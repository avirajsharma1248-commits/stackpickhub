# StackPick 30-article content plan (US small business searches)

Publish 2-3 per week. Start with comparison and "best for" pages, since they match buying intent and earn affiliate commission.
For each page: answer one question, test the tools yourself, add a comparison table, link to related tool pages, and add a "Last reviewed" date.

## Weekly routine
- Monday: pick the question, check Google's top 3 results, note what they are missing
- Tuesday-Wednesday: test the tools, take notes and screenshots, write
- Thursday: publish, add internal links, request indexing in Search Console
- Friday: share in one community where the question is asked; review Search Console data
